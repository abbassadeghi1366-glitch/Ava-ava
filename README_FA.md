# آوا (AVA AI) — بسته آماده توسعه اندروید

این بسته شامل برنامه اندروید، سرور نمونه و مدل سه‌بعدی اسکلت‌دار آوا است.

## قابلیت‌های موجود
- رابط اندرویدی با گفت‌وگوی فارسی و اتصال به API هوش مصنوعی از طریق سرور
- تبدیل گفتار به متن و خواندن پاسخ با صدای Android Text-to-Speech
- آواتار سه‌بعدی GLB با اسکلت و انیمیشن‌های `Idle`، `Walk`، `Run` و `Wave`
- دکمه شروع/توقف راه‌رفتن آواتار
- ساخت پیش‌نویس و تأیید کاربر پیش از ارسال پیام تلگرام
- سرور Node.js و نمونه endpoint برای دستیار و تلگرام

## پیش‌نیازها
- Android Studio و Android SDK 35
- JDK 17 و Gradle 8.9
- Node.js 20 یا جدیدتر برای اجرای سرور

## اجرای برنامه اندروید
1. پوشه `android` را در Android Studio باز کنید.
2. اجازه دهید Gradle Sync کامل شود.
3. در فایل `android/app/build.gradle.kts` مقدار `BASE_URL` را تنظیم کنید. برای گوشی واقعی باید آدرس IP یا دامنه سرور در دسترس گوشی را وارد کنید؛ `10.0.2.2` فقط برای شبیه‌ساز اندروید است.
4. از منوی Build گزینه Build APK(s) را انتخاب کنید یا برنامه را روی گوشی اجرا کنید.

## اجرای سرور
```bash
cd backend
cp .env.example .env
# مقادیر واقعی را در .env قرار دهید
npm install
npm start
```

کلید API هوش مصنوعی و توکن تلگرام باید فقط در فایل `.env` روی سرور بمانند و نباید داخل APK قرار بگیرند. برای استفاده از خارج شبکه محلی، سرور را با HTTPS و احراز هویت منتشر کنید.

## ساخت APK با GitHub Actions
فایل workflow در `.github/workflows/android.yml` قرار دارد. پس از قراردادن محتویات این بسته در مخزن GitHub، از بخش Actions، گردش‌کار **Build Ava Android APK** را اجرا کنید. فایل APK در بخش Artifacts همان اجرای workflow قرار می‌گیرد.

## محدودیت‌های فعلی
- این بسته سورس پروژه است، نه APK از پیش ساخته‌شده؛ در این محیط ساخت و نصب APK روی گوشی تأیید نشده است.
- برای پاسخ‌گویی واقعی هوش مصنوعی باید سرور اجرا و کلید API در `.env` تنظیم شود.
- تلگرام نیازمند توکن ربات و `chat_id` معتبر است. ارسال پیام فقط با تأیید کاربر انجام می‌شود.
- اتصال و ارسال پیام اینستاگرام هنوز پیاده‌سازی عملیاتی ندارد و به API رسمی Meta و مجوزهای لازم نیاز دارد.
- این نسخه نمونه توسعه است و پیش از انتشار عمومی به آزمون امنیتی و عملکردی نیاز دارد.

## اتصال دایرکت اینستاگرام

در این نسخه، بک‌اند ارسال واقعی پیام از طریق API رسمی Meta و دریافت رویدادهای دایرکت با Webhook را دارد. برای فعال‌سازی:

1. حساب اینستاگرام باید Professional از نوع Business یا Creator باشد.
2. در Meta for Developers یک اپ بساز و Instagram Messaging / Instagram API with Instagram Login را فعال کن.
3. مجوز `instagram_business_manage_messages` را درخواست کن؛ برای استفاده عمومی، App Review و دسترسی Advanced لازم است.
4. دسترسی ابزارهای متصل به پیام‌ها را در تنظیمات اینستاگرام روشن کن.
5. متغیرهای `INSTAGRAM_API_MODE=instagram_login`، `INSTAGRAM_ACCESS_TOKEN` و `INSTAGRAM_USER_ID` را در محیط سرور تنظیم کن. هیچ توکنی را داخل APK یا GitHub قرار نده.
6. وب‌هوک HTTPS با آدرس `https://YOUR-DOMAIN/webhooks/instagram` ثبت کن، مقدار `META_VERIFY_TOKEN` را در Meta و سرور یکسان بگذار و رویداد `messages` را فعال کن. `META_APP_SECRET` را نیز در سرور قرار بده.
7. پس از دریافت اولین دایرکت، شناسه اختصاصی مخاطب از وب‌هوک ثبت می‌شود. با `GET /api/instagram/inbox` و هدر `Authorization: Bearer AVA_ADMIN_TOKEN` پیام‌های دریافت‌شده را ببین.
8. در اپ آوا، اینستاگرام را انتخاب کن، متن پیام و IG-scoped ID گیرنده را وارد کن، پیش‌نویس بساز و بعد از بررسی، ارسال را تأیید کن.

برای Messenger API for Instagram مقدار `INSTAGRAM_API_MODE=messenger` را انتخاب کن و توکن و مجوزهای همان روش را بگیر. توکن‌ها فقط باید در سرور باشند.

توجه: حساب شخصی معمولی پشتیبانی نمی‌شود؛ مخاطب باید ابتدا به حساب حرفه‌ای پیام داده باشد. محدودیت پنجره پاسخ‌گویی و سیاست‌های ضداسپم Meta رعایت شود. پیام‌های وب‌هوک در این نسخه در حافظه موقت سرور نگهداری می‌شوند. تا زمانی که اپ Meta، مجوزها، توکن‌ها و دامنه HTTPS تنظیم نشوند، اتصال واقعی فعال نیست.
