# آوا (AVA AI) — نسخه توسعه‌یافته

این پروژه نمونه‌ای برای اتصال برنامه Android به یک سرور Node.js است:
- گفت‌وگوی فارسی با مدل زبانی از طریق API سرور
- تبدیل گفتار به متن اندروید و خواندن پاسخ با TextToSpeech
- ساخت پیش‌نویس پاسخ و تأیید کاربر قبل از ارسال
- نمونه ارسال پیام از طریق Telegram Bot API
- اسکلت اتصال Instagram Messaging API (نیازمند حساب حرفه‌ای، مجوزها و دسترسی تأییدشده Meta)

## نیازمندی‌ها
- Android Studio جدید
- Android SDK 35، JDK 17
- Node.js 20 یا بالاتر
- کلید API مدل هوش مصنوعی
- برای تلگرام: توکن ربات از BotFather و chat_id مجاز
- برای اینستاگرام: حساب حرفه‌ای Instagram، اپ Meta، توکن معتبر و مجوزهای مورد تأیید

## راه‌اندازی سرور
```bash
cd backend
cp .env.example .env
# فایل .env را با مقادیر واقعی پر کنید
npm install
npm start
```
سرور به طور پیش‌فرض روی `http://localhost:8787` اجرا می‌شود. برای گوشی واقعی، `localhost` را در `BASE_URL` اندروید با IP محلی کامپیوتر جایگزین کنید و هر دو دستگاه روی شبکه یکسان باشند.
برای تست شبیه‌ساز Android، آدرس میزبان معمولاً `http://10.0.2.2:8787` است.

**امنیت:** کلید مدل هوش مصنوعی و توکن‌های تلگرام/متا را داخل برنامه اندروید قرار ندهید. فقط روی سرور در `.env` نگه دارید. فایل `.env` را منتشر نکنید. برای استفاده بیرون از شبکه محلی، HTTPS، احراز هویت و محدودسازی دسترسی ضروری است.

## ساخت Android
1. پوشه `android` را در Android Studio باز کنید.
2. منتظر Sync Gradle بمانید.
3. مقدار `BASE_URL` در `android/app/build.gradle.kts` را تنظیم کنید.
4. Run را بزنید.

## نکته درباره پیام‌رسان‌ها
- تلگرام: ربات فقط می‌تواند با کاربرانی که ربات را شروع کرده‌اند یا در محدوده مجاز API هستند کار کند؛ `chat_id` باید به‌درستی تنظیم شود.
- اینستاگرام: ارسال پیام فقط با API رسمی و در محدوده مجوزها/قوانین Meta ممکن است. این نمونه عمداً پیام واقعی اینستاگرام را بدون تنظیمات رسمی انجام نمی‌دهد؛ تا وقتی متغیرهای مربوطه تکمیل نشده‌اند، خطای توضیحی برمی‌گرداند.
- ارسال پیام تنها پس از فشردن دکمه «تأیید و ارسال» انجام می‌شود.
- این نسخه نمونه توسعه است، نه محصول نهایی ممیزی‌شده یا APK کامپایل‌شده.

## API سرور
- `GET /health`
- `POST /api/assistant` `{ "message": "..." }`
- `POST /api/draft` `{ "platform": "telegram", "recipient": "...", "incomingMessage": "..." }`
- `POST /api/send/telegram` `{ "chatId": "...", "text": "..." }`
- `POST /api/send/instagram` `{ "recipientId": "...", "text": "..." }`
