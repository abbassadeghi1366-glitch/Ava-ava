# آوا (Ava AI) — پروژه آماده بارگذاری در GitHub

این مخزن شامل سورس اندروید، سرور نمونه و گردش‌کار ساخت APK است.

## محتویات
- `android/` برنامه Android با Kotlin و Jetpack Compose
- `backend/` سرور Node.js برای اتصال امن به سرویس هوش مصنوعی و تلگرام
- `.github/workflows/android.yml` ساخت APK با GitHub Actions

## بارگذاری در GitHub
1. در GitHub یک مخزن خالی بسازید (مثلاً `Ava-ava`).
2. فایل ZIP را روی گوشی یا رایانه استخراج کنید.
3. محتویات پوشه `Ava-Project-Upload` را در ریشه مخزن قرار دهید؛ پوشه‌های `android`، `backend` و `.github` باید مستقیماً در ریشه باشند.
4. تغییرات را Commit کنید.
5. در تب **Actions** گردش‌کار **Build Ava Android APK** را اجرا کنید (یا پس از Push خودکار اجرا می‌شود).
6. پس از موفقیت، از صفحه اجرای workflow بخش **Artifacts** فایل `Ava-debug-APK` را دریافت کنید.

## اجرای سرور
در پوشه `backend` فایل `.env.example` را به `.env` کپی و مقادیر واقعی را تنظیم کنید، سپس:

```bash
npm install
npm start
```

کلید API و توکن ربات را فقط در متغیرهای محیطی سرور نگه دارید. هرگز `.env` یا کلیدها را در GitHub یا داخل APK بارگذاری نکنید.

## تنظیم آدرس سرور در اپ
در `android/app/build.gradle.kts` مقدار `BASE_URL` را برای سرور واقعی با آدرس HTTPS جایگزین کنید. مقدار فعلی `10.0.2.2` فقط برای شبیه‌ساز اندروید مناسب است و روی گوشی واقعی کار نمی‌کند.

## وضعیت و محدودیت‌ها
- این بسته سورس پروژه است، نه APK آماده نصب.
- ساخت و نصب APK در این محیط انجام و تأیید نشده است؛ نتیجه واقعی پس از اجرای GitHub Actions مشخص می‌شود.
- برای پاسخ هوش مصنوعی و تلگرام باید سرور و اطلاعات دسترسی معتبر تنظیم شوند.
- اتصال عملیاتی اینستاگرام هنوز پیاده‌سازی نشده و نیازمند API رسمی Meta و مجوزهای آن است.
- پیش از انتشار عمومی، تست امنیتی، تست روی گوشی واقعی و تنظیم HTTPS لازم است.

## اتصال رسمی دایرکت اینستاگرام

این نسخه مسیر واقعی ارسال پیام را در بک‌اند اضافه می‌کند و وب‌هوک پیام‌های ورودی را دریافت می‌کند. برای فعال‌شدن اتصال واقعی، مالک حساب باید مراحل Meta را انجام دهد:

1. حساب Instagram را به **Professional (Business یا Creator)** تبدیل کن. حساب شخصی معمولی برای این API کافی نیست.
2. در Meta for Developers یک اپ بساز و محصول Instagram Messaging / Instagram API with Instagram Login را پیکربندی کن.
3. مجوز پیام‌رسانی `instagram_business_manage_messages` را (و مجوز پایه متناسب با جریان ورود) درخواست و تأیید کن. برای کاربران خارج از نقش‌های توسعه‌دهنده/تستر، App Review و دسترسی پیشرفته لازم است.
4. در تنظیمات پیام‌های اینستاگرام، دسترسی ابزارهای متصل به پیام‌ها را فعال کن.
5. در محیط سرور، مقادیر `INSTAGRAM_API_MODE=instagram_login`، `INSTAGRAM_ACCESS_TOKEN` و `INSTAGRAM_USER_ID` را وارد کن. توکن و App Secret فقط روی سرور باشند.
6. آدرس عمومی HTTPS وب‌هوک را در Meta ثبت کن: `https://YOUR-DOMAIN/webhooks/instagram`؛ مقدار `META_VERIFY_TOKEN` را در Meta و سرور دقیقاً یکسان وارد کن و رویداد `messages` را فعال کن. `META_APP_SECRET` را هم روی سرور تنظیم کن تا امضای درخواست‌های وب‌هوک بررسی شود.
7. یک کاربر باید ابتدا به حساب حرفه‌ای شما دایرکت بدهد. وب‌هوک شناسه اختصاصی همان کاربر (IG-scoped ID) را دریافت می‌کند. برای مشاهده پیام‌های دریافتی از مسیر `GET /api/instagram/inbox` با هدر `Authorization: Bearer AVA_ADMIN_TOKEN` استفاده کن.
8. در برنامه آوا، پلتفرم اینستاگرام را انتخاب کن، متن پیام را وارد کن، شناسه اختصاصی گیرنده را وارد کن، پاسخ پیشنهادی را بساز و بعد از بررسی، ارسال را تأیید کن.

برای استفاده از مسیر Messenger API به‌جای Instagram Login، `INSTAGRAM_API_MODE=messenger` را انتخاب کن و توکن/مجوزهای مربوط به Messenger API for Instagram را طبق تنظیمات همان اپ Meta بگیر. حالت API و نوع توکن باید با هم مطابقت داشته باشند.

**محدودیت‌ها:** API فقط در چارچوب قوانین پیام‌رسانی Meta کار می‌کند؛ معمولاً مخاطب باید ابتدا به حساب حرفه‌ای پیام داده باشد و پاسخ‌گویی در پنجره مجاز پیام‌رسانی (معمولاً ۲۴ ساعت) انجام شود. پیام ناخواسته/انبوه ارسال نکن. دریافت وب‌هوک در حافظه موقت سرور نگهداری می‌شود؛ برای محیط عملیاتی، ذخیره‌سازی پایدار و احراز هویت قوی‌تر لازم است. این اتصال تا زمانی که اپ Meta، مجوزها، توکن و HTTPS واقعی تنظیم نشوند، فعال نخواهد شد.
